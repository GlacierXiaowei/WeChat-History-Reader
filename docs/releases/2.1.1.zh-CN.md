# 🚀 读懂微信 2.1.1

**这是项目的首个 GitHub 正式发布包，汇总从 1.1.0 到 2.1.1 的完整升级。**

让 AI 读懂你的微信聊天，帮你回顾讨论、查找决定、整理待办。这次升级重新设计了面向 AI 的读取格式，加入长对话快照，并将旧版 MCP 运行方式替换为技能驱动的本地命令行。📚

## ✨ 从 1.1 到现在，更新了什么？

### 更适合 AI 的聊天读取

- 新增默认紧凑模式 `compact`，以结构化行返回聊天内容，减少重复字段和与分析无关的元数据。
- 针对不同场景提供不同列：单聊保留时间、双方角色和内容；群聊保留时间、发言人和内容；跨聊天读取同时保留所属会话。
- 每条消息保留时间，图片、语音、文件等非文字内容使用简短标记，方便理解对话上下文。
- 将证据核对与日常总结分开：需要消息标识、结构化字段或图片解码时使用 `records`，原始载荷只在明确需要时读取。
- 首页声明读取类型和列定义，续页只返回必要的结果与分页信息，避免重复描述。

### 长对话快照与更稳定的分页

- 新增长对话机器快照：固定聊天、关键词和时间范围，一次生成后分批读取，不必每一页都重新扫描实时数据库。
- 快照与用户主动导出的文件分开保存，区分机器续读缓存和长期保留的导出结果。
- 创建快照和导出时使用固定的本地数据库副本，避免同一次长读取混入不同时间的数据库状态。
- 支持跨命令行进程继续使用实时分页游标，修复首次后台加载导致游标失效的问题。
- 游标绑定会话、模式、筛选条件与数据源；刷新、切换账号或数据源变化后明确失效，避免悄悄漏读或重复读取。

### 会话定位与读取流程更清晰

- 已知联系人、群聊或聊天标识时直接读取；名称有歧义时再查找会话，减少不必要的往返。
- 支持按关键词和时间范围筛选聊天内容，并区分单聊、群聊与跨聊天近期消息。
- 群人数只作为候选排序线索，不因人数估计不准确而隐藏有效候选。
- 保留聊天导出和图片解码能力；导出需要明确请求，图片标识来自实际读取结果，不凭空猜测。

## 🛠️ 全新的运行与安装方式

- 插件标识由 `get-wechat-history` 调整为 `wechat-history-reader`，中文名称为“读懂微信”。
- 2.1.1 只包含技能、本地 JSON 命令行及其运行依赖，不再加载 MCP 服务。
- 所有业务操作统一通过随包的 `scripts/plugin_bootstrap.cmd` 启动。
- 首次执行业务命令时创建私有虚拟环境，仅从随包依赖文件离线安装，不访问 PyPI，也不在失败时退回联网安装。
- 根据版本、源码、依赖包与安装标记判断是否需要准备环境，避免重复安装。
- 清理旧版 MCP 配置、服务入口、历史工具封装和开发生成物，保留标准插件清单与 Codex 兼容清单。

## 🩺 诊断与修复，各司其职

- 普通 `doctor` 严格只读：不创建虚拟环境、不安装依赖、不扫描密钥，也不刷新聊天数据。
- `doctor --repair` 只修复私有运行环境与安装标记，不负责账号配置、密钥提取或聊天数据刷新。
- 分别检查运行环境与微信数据状态，避免把“运行环境正常”误判为“微信已配置”，或把“无法诊断”误判为“微信未运行”。
- 澄清安装标记过期的含义：它不一定表示依赖损坏，修复也不等于强制重装。

## 🐛 修复与提示词完善

- 修复命令失败时的退出码与错误处理，避免将失败误判为成功或零条结果。
- 修复诊断命令对自定义状态目录的处理。
- 修复私有虚拟环境目录存在、但其中解释器缺失时的重建逻辑。
- 纳入 2026 年 10 月 8 日追加的提示词修正，明确插件路径定位、诊断边界、分页条件、错误输出和实际兼容范围。
- 插件界面保留聊天总结、证据查询和待办整理三条默认提示，不展示诊断提示；给 AI 阅读的技能说明仍保留完整诊断流程与调用方法。
- 同步使用文档、依赖说明和微信版本兼容说明，避免错误描述引导 AI 调用旧版接口或擅自修复环境。

## 📦 安装条件与发布附件

- 支持 Windows 64 位系统。
- 用户需自行安装 Python，并确保 `py` 或 `python` 命令可用；发布包不包含解释器，也不会自动安装 Python。
- 内置适用于 Windows 64 位、CPython 3.10 至 3.14 的依赖安装包，建议使用此范围内的解释器。
- 其他系统、架构或解释器版本不保证具有兼容依赖。
- 首次配置或切换账号时，请保持微信桌面端登录。

下载附件 **`wechat-history-reader-2.1.1.zip`**。这是包含插件清单、技能、本地启动器、运行源码和离线依赖的完整插件包，不是需要自行补齐依赖文件的普通源码压缩包。

## ⚠️ 从 1.1 升级前，请留意

- 这是运行入口与读取协议都有变化的升级，旧版 MCP 工具调用方式不能直接沿用；请使用当前插件的技能和启动器。
- 默认状态目录调整为 `%LOCALAPPDATA%\WeChatHistoryReader`。不要假定旧目录下的配置会自动迁移；若诊断显示未配置，请按当前说明重新配置。
- 保留 1.1 已有的微信 4.1.13 现代密钥恢复与旧格式回退能力，但不保证兼容所有后续微信版本。
- 实时续页必须保持会话、模式、筛选条件与状态目录一致，不要在两页之间执行刷新；固定快照续页不会重新刷新实时数据。
- `--state-root` 必须放在子命令前，只选择配置、缓存和快照等状态目录，不改变插件目录或私有虚拟环境位置。

需要排查时，可先在插件目录执行只读诊断：

```text
scripts/plugin_bootstrap.cmd doctor
```

确认需要修复私有运行环境后，再执行：

```text
scripts/plugin_bootstrap.cmd doctor --repair
```

路径或密钥问题应通过账号配置流程处理，不能仅靠运行环境修复解决。

## 🔒 本地处理与数据边界

插件的数据库读取、解密、缓存和导出均在本机进行，不修改微信原始数据库。发布包不包含个人配置、数据库密钥、聊天记录、运行缓存或开发环境。

交给 AI 的读取结果仍受所用 AI 服务的数据处理规则约束；“本地读取”不等于聊天内容不会进入模型上下文。
